# Tarea de tarjetas

Hecho por Giuliano Jaramillo

## Descripción del proyecto

Se realizaron las dos tarjetas que se pidio como tarea que se replicaran, se uso HTML y CSS.

## Estructura del proyecto

- `index.html`: contiene la estructura de las dos tarjetas.
- `css/styles.css`: contiene los estilos de la página.
- `img/`: carpeta donde se guardaron las imágenes utilizadas.
- `README.md`: información sobre el codigo y sobre como se hizo todo.

## Herramientas utilizadas

- **HTML:** para crear la estructura de las tarjetas.
- **CSS:** para trabajar los colores, tamaños y espacios.
- **CSS Grid:** para colocar las dos tarjetas una al lado de la otra.
- **Flexbox:** para organizar y centrar los iconos.
- **Font Awesome:** para agregar los iconos de las redes sociales.
- **Clip-path:** para hacer los cortes en la parte superior e inferior de las tarjetas.
- **Media Queries:** para que las tarjetas se acomoden según el tamaño de la pantalla.
- **BEM:** para organizar mejor los nombres de las clases CSS.

## ¿Cómo funciona?

En HTML se crearon las dos tarjetas con imágenes, nombres, descripciones e iconos.

En el CSS se utilizaron Grid y Flexbox para organizar los elementos y tambien se uso clip-path para las formas de la tarjeta.

## Diseño responsive

Se realizaron pruebas y la pagina funciona y se ve perfectamente en computadores, celulares y tablets.
